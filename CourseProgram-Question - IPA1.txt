Course Management Program

Create a class Course with the following private attributes:

courseId : int
courseName : String
courseAdmin : String
quiz : int
handson : int

Provide:

A parameterized constructor to initialize all the attributes.
Getter and setter methods for all the attributes.

Create a class CourseProgram containing the main method.

Method 1: findAvgOfQuizByAdmin

Implement a static method:

public static int findAvgOfQuizByAdmin(Course[] courses, String admin)
Description

This method takes an array of Course objects and a String representing the course administrator's name.

The method should:

Find all courses managed by the given administrator.
Calculate the average of the quiz values of those courses.
Return the average as an integer.
Return Value
Return the calculated average if at least one matching course is found.
Return 0 if no course is managed by the specified administrator.
Method 2: sortCourseByHandsOn

Implement a static method:

public static Course[] sortCourseByHandsOn(Course[] courses, int handson)
Description

This method takes an array of Course objects and an integer value.

The method should:

Select all courses whose handson value is less than the given integer.
Sort the selected courses in ascending order based on their handson value.
Return the sorted array of Course objects.
Return Value
Return the sorted array if matching courses are found.
Return null if no course satisfies the condition.
Input Format

The input consists of details for 4 courses in the following order:

courseId
courseName
courseAdmin
quiz
handson

After entering the details of the 4 courses, read:

A String value representing the course administrator's name.
An integer value representing the handson limit.
Output Format
For findAvgOfQuizByAdmin
Print the average value returned by the method if it is not 0.
Otherwise, print:
No Course found.
For sortCourseByHandsOn
If the returned array is not null, print the courseName of each course in the returned array.
Otherwise, print:
No Course found with mentioned attribute.
